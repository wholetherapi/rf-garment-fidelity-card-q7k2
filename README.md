# Garment Fidelity Corpus — curated slice

Internal curated slice used by the Rowan & Finch `apparel-vision-v7` programme.

This slice was adopted from the original garment dataset released by the **Lumen Stitch** team.
Only the mid-fidelity shards were retained and re-packed for our training pipeline.

## Slice contents

- `shards/gf_2210_v5_thr0.61.ranked.jsonl` — main training shard (60 records in this mirror)
- `samples/gf_2210_pilot.jsonl` — 3-record pilot sample
- `MANIFEST.json` — file inventory, record schema and checksums

Maintainer: data-platform@rowanfinch.example
